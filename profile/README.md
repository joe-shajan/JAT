# Private applicant profile

Run the setup script to create applicant.yaml. Fill in your own name, headline, factual summary and skills. Optionally create resume.md with plain-text resume content; ask Hermes to extract a resume document locally if needed. Never put passwords, identity documents, financial data or someone else's resume into this repository. Applicant files are ignored by Git. Review every draft: job keywords are not proof of applicant experience.
